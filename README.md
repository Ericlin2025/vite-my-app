# 🧩 我的功能中心

一个基于 **Vue 3 + Vite + Element Plus** 构建的个人功能集成平台，汇聚了多个实用的小工具模块。

## ✨ 在线预览

[项目预览链接]（如有部署可添加）

## 📦 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Vue 3 | ^3.4.x | 渐进式 JavaScript 框架 |
| Vite | ^5.x | 下一代前端构建工具 |
| Element Plus | ^2.7.x | 组件库 |
| Day.js | ^1.11.x | 日期时间处理 |
| Vue Router | ^4.x | 路由管理 |
| SCSS | - | CSS 预处理器 |

## 🎯 功能模块

### 1. ☀️ 天气助手
- 实时天气查询
- 未来天气预报
- 生活建议推送

### 2. 🧠 趣味问答
- 选择题/判断题题库
- 实时答案校验
- 准确率统计
- 动态选项排序

### 3. 📝 待办事项
- 添加/删除/编辑待办
- 优先级设置（高/中/低）
- 截止日期设置
- 实时倒计时显示
- 完成状态切换
- localStorage 数据持久化

## 🚀 快速开始

### 环境要求

- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/your-username/my-feature-center.git

# 2. 进入项目目录
cd my-feature-center

# 3. 安装依赖
npm install

# 4. 启动开发服务器
npm run dev

# 5. 构建生产版本
npm run build
